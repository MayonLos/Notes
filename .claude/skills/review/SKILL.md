# review：复习与自测（只读）

知识库的价值在复习时才兑现。这个 skill 只做三件事：**考我 / 排队 / 找洞**。

## 触发

- `/review`：整体学习状态（覆盖、复习队列、缺口、TODO 进度）。
- `/review 锁存器和触发器`：针对某页出自测题并批改。
- `/review 触发器 --提纲`：把某章做成默写/背诵提纲。
- 「考考我」「哪些该复习了」「知识库还缺什么」「学到哪了」「哪些笔记很久没动了」。

不触发：
- 「二阶系统的超调量公式是什么」→ `query`（问知识本身，不是问学习状态）。
- 「frontmatter 有没有写错 / 有没有死链」→ `lint`（问文件合不合规）。
- 要补页 → `note`。本 skill 只读，发现缺口只提示，不代写。

## 硬边界

- 全程只读。看板与题目**不写进 Vault**，除非用户明确要求，且那时交给 `note`。
- 出题只能基于笔记里真实存在的内容；笔记没写的知识点不要当成「你应该会」来考，而是列为缺口。
- 批改要指出证据在哪一页哪一节；笔记本身就没写清楚的，说明是笔记的问题不是答题人的问题。

## 用法

```bash
ROOT=/home/mayon/Vaults
R="$ROOT/.claude/skills/review/scripts/study_status.py"

python3 "$R" --root "$ROOT"                          # 整体看板
python3 "$R" --root "$ROOT" --subject control        # 只看一个学科
python3 "$R" --root "$ROOT" --stale-days 30          # 收紧复习阈值
python3 "$R" --root "$ROOT" --points wiki/concepts/digital/锁存器和触发器.md   # 抽考点骨架
```

`--points` 抽出小标题、公式、加粗术语、表格行和关联页——**用它出题，不要整页读进来**；只有批改时需要核对细节，才用 `query` 的 `--outline` + `sed` 读对应片段。

## 三种输出

### 1. 学习状态看板（`/review` 无参）

```markdown
# 学习状态 — YYYY-MM-DD

## 覆盖
自控 4 页 / 数电 7 页 / C++ 4 页

## 该复习了（越久没动越靠前）
- 132 天 · [[基础语法]] — 建议 15 分钟过一遍易错点

## 知识缺口
- 待写页面：[[稳态误差]]（2 处引用在等）、[[传递函数]] …
- 页内标记：[[自动控制原理]] 有 4 处 `待补充`；[[逻辑函数化简]] 有 1 处 `待验证`

## TODO 进度
自动控制原理 0/20 · C++ 0/25 …

## 建议下一步
1. 先补 [[传递函数]]：它是 6 页的前置，缺它整条链断着
2. …
```
排序讲理由：被引用次数、是否是前置概念、久未复习程度，三者优先于页面数量。

### 2. 自测题（`/review <页面>`）

- 5–8 题，覆盖**定义 → 推导 → 应用 → 易错**四个层次，难度递增。
- 每题标注考点出自哪一节；答案先不给，等用户作答。
- 用户答完再逐题批改：对/错/不完整 + 正确答案 + 页面锚点 `[[页面#小节]]`。
- 答错集中的地方，提示这块笔记可能需要 `/note` 补充，但不代写。

### 3. 缺口报告（「知识库还缺什么」）

按学科列：待写页面（谁在等它）、`待补充/待验证/知识冲突` 标记、TODO 里长期未动的分支、只有孤立页没有链条的主题。每项给一句「补它的收益」。

### 4. 默写提纲（「做成默写提纲 / 背诵材料」）

用 `--points` 抽出的骨架，把页面压成可默写的形式：小标题作层级，关键结论、公式、表格行挖空成填空，术语列成一行待解释清单。**只挖笔记里真有的内容**，不补充笔记没写的知识点。默认不给答案，用户要对答案时再附上，并标出处 `[[页面#小节]]`。

## 输出契约

`study_status.py`：默认看板打印 `study_status: <范围> — 页面 N / 待复习 N / 待写 N / 缺口标记 N` 及五个分区；`--points` 打印单页考点骨架；`--json` 输出 `{tool, root, status, mode, coverage, review_queue, planned_pages, gaps, todo_progress, totals}`。`--limit N` 控制各分区条数（默认 10），`--stale-days N` 调复习阈值（默认 60）。退出码 `0`，仅在找不到 `wiki/` 时为 `1`。
