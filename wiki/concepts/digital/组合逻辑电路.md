> **一句话定义**：任意时刻输出**只取决于当前输入**、与历史状态无关（无记忆元件）的数字电路，由基本逻辑门搭成。

> **后续**：→ [[锁存器和触发器]]（加上记忆，进入时序逻辑）

## 直觉

组合逻辑的定义可以反过来读：**没有反馈，就没有记忆**。信号从输入单向流到输出，电路里不存在任何环路，所以它本质上就是一张真值表的硬件实现。

这带来两个结论：

1. **任何组合功能都能实现**，而且方法是机械的：真值表 → 卡诺图 → 两级门电路。没有创造性可言，只有成本高低之分。
2. **成本才是真问题**。所以本页的一半内容其实是「怎么少花门」——用现成的 MSI 芯片（MUX、译码器、加法器）代替一堆散门。

这里有个反复出现的核心洞察：**译码器和 MUX 的本质都是最小项发生器**。

- $n$-$2^n$ 译码器把 $n$ 个变量的**全部** $2^n$ 个最小项都产生出来，你只要把需要的那几个或起来
- $2^n$ 选 1 MUX 的输出 $Y=\sum \bar S\ldots D_i$ 就是最小项之和，把 $D_i$ 接 0/1 就等于在选择哪些最小项

所以「用译码器/MUX 实现任意逻辑函数」不是技巧，是它们定义的直接推论。

最后一块是**竞争与冒险**——这是组合逻辑唯一「不那么组合」的地方：理想模型里输出瞬间跟随输入，真实电路里不同路径延迟不同，切换瞬间会冒出毛刺。真值表是对的，波形却是错的。这提醒一件事：**组合逻辑的正确性只在信号稳定后才成立。**

## 原理与推导

### 设计流程

```
需求分析 → 定义 I/O → 列真值表 → 写表达式 → 卡诺图化简 → 画电路图
```

> 逻辑门的公式与真值表见 [[逻辑代数]]；化简方法见 [[逻辑函数化简]]。

### 加法器

**半加器**（Half Adder）——只加两个 1 位数，**不处理低位进位**

![[half_adder.png]]

| 输出 | 表达式 |
|:---|:---|
| 和位 S | $S = A \oplus B$ |
| 进位 Cout | $C_{out} = A \cdot B$ |

**一位全加器**（Full Adder）——增加进位输入 $C_{in}$，可级联

![[full_adder.png]]

| 输出 | 表达式 |
|:---|:---|
| 和位 S | $S = A \oplus B \oplus C_{in}$ |
| 进位 Cout | $C_{out} = A\cdot B + (A \oplus B)\cdot C_{in}$ |

> [!note] 两个输出的直观含义
> - $S$ = 三个输入的**奇偶校验**（1 的个数为奇数则 $S=1$）
> - $C_{out}$ = 三个输入中**至少有两个为 1**（多数表决）

**多位加法器**

![[multi_bit_adder.png]]

行波进位：$N$ 个全加器串联，低位 $C_{out}$ → 高位 $C_{in}$。

| 改进方案 | 原理 | 延迟 |
| :--- | :--- | :--- |
| **超前进位**（Carry Look-ahead） | 并行计算所有进位 | $O(\log N)$ |
| **进位选择**（Carry Select） | 预计算两种进位结果再选 | $O(\sqrt N)$ |

### 数据选择器 MUX

从多路输入中**选一路**输出——「多路开关」。

**4 选 1**

![[mux_4to1.png]]

$$Y = \bar{S_1}\bar{S_0}D_0 + \bar{S_1}S_0 D_1 + S_1\bar{S_0}D_2 + S_1 S_0 D_3$$

| $S_1$ | $S_0$ | $Y$ |
|:---:|:---:|:---:|
| 0 | 0 | $D_0$ |
| 0 | 1 | $D_1$ |
| 1 | 0 | $D_2$ |
| 1 | 1 | $D_3$ |

**8 选 1**

![[mux_8to1.png]]

数据输入 $D_0\sim D_7$，选择控制 $S_0\sim S_2$。常见芯片：**74LS151**（含互补输出）、**74LS153**（双 4 选 1）。

### 多路分配器 DEMUX

把单路输入分配到多路输出中的某一路——「单刀多掷开关」。

![[demux_1to4.png]]

| $S_1$ | $S_0$ | 输出 |
|:---:|:---:|:---|
| 0 | 0 | $Y_0 = D$，其余 0 |
| 0 | 1 | $Y_1 = D$，其余 0 |
| 1 | 0 | $Y_2 = D$，其余 0 |
| 1 | 1 | $Y_3 = D$，其余 0 |

> [!important] DEMUX = 译码器 + 数据输入
> 把译码器的使能端 EN 改成数据输入端 D，就是 DEMUX。两者是同一个电路的两种用法。

### 编码器

把 $2^n$ 条输入线编成 $n$ 位二进制输出。

| | 基本编码器 | 优先编码器 |
|:---|:---|:---|
| 输入约束 | 同时只能有 1 个有效 | 允许多个同时有效 |
| 冲突处理 | 输出不确定 | 响应**优先级最高**的输入 |

**8 线-3 线优先编码器**

![[encoder_8to3.png]]

| 优先级 | 输入 | 输出 $Y_2Y_1Y_0$ |
|:---:|:---:|:---:|
| 最高 | $I_7$ | 111 |
| ↓ | $I_6$ | 110 |
| 最低 | $I_0$ | 000 |

- **GS**（Got Something）：至少一个输入有效——用来区分「$I_0$ 有效」和「无任何输入」
- **EO**（Enable Out）：无任何输入有效，用于级联扩展

常见芯片：**74LS148**。

### 译码器

把 $n$ 位二进制输入译成 $2^n$ 条互斥输出线中的一条。

**2 线-4 线**

![[decoder_2to4.png]]

$$Y_0 = \bar{A_1}\bar{A_0}, \quad Y_1 = \bar{A_1}A_0, \quad Y_2 = A_1\bar{A_0}, \quad Y_3 = A_1 A_0$$

**3 线-8 线**

![[decoder_3to8.png]]

常见芯片 **74LS138**（含 3 个使能端，便于级联）。级联扩展：用最高位 + 反相器控制两片 138 的使能端，得到 4-16 译码器。

> [!important] 译码器 = 最小项发生器
> 每个输出对应一个**最小项**。$n$-$2^n$ 译码器产生 $n$ 个变量的**全部最小项**——译码器 + OR（或低有效时 + NAND）= 任意组合逻辑函数。

**七段译码显示**

![[seven_segment.png]]

| 类型 | 公共端 | 亮灯条件 | 常用译码器 |
|:---|:---:|:---|:---|
| **共阴极** | 接地 | 段驱动 = 1 | 74LS48 |
| **共阳极** | 接 VCC | 段驱动 = 0 | 74LS47 |

### 数值比较器

**1 位比较器**

![[comparator_1bit.png]]

| 输出 | 表达式 |
|:---|:---|
| $A > B$ | $A \cdot \bar B$ |
| $A = B$ | $A \odot B$（同或）|
| $A < B$ | $\bar A \cdot B$ |

**多位比较器**

![[comparator_multibit.png]]

算法：**从 MSB 向 LSB 逐位比较，第一个不相等的位决定结果**。

$$EQ = (A_3 \odot B_3)(A_2 \odot B_2)(A_1 \odot B_1)(A_0 \odot B_0)$$

常见芯片 **74LS85**（4 位，含级联输入端）。

### 竞争与冒险

![[hazard_timing.png]]

- **竞争（Race）**：多个信号经不同路径到达同一点，到达时间有先后
- **冒险（Hazard）**：竞争导致输出出现**短暂的错误脉冲**（毛刺 / Glitch）

> [!important] 竞争是原因，冒险是结果
> 有竞争**不一定**有冒险，但有冒险**一定**有竞争。

| 类型 | 描述 |
|:---|:---|
| **静态 1 冒险** | 输出应稳定为 1，却出现短暂的 0 脉冲 |
| **静态 0 冒险** | 输出应稳定为 0，却出现短暂的 1 脉冲 |
| **动态冒险** | 输出应只变一次，却多次跳变后才稳定 |

**卡诺图判别**：两个**相邻但不重叠**的圈，输入跨越两圈边界时可能出冒险。

| 消除方法 | 原理 | 适用场景 |
|:---|:---|:---|
| **增加冗余项** | 在相邻圈之间加一个覆盖两者的乘积项 | FPGA / 定制逻辑（推荐）|
| **滤波电容** | 输出端加小电容滤掉窄脉冲 | 低速、非关键路径 |
| **时钟采样** | 只在时钟沿采样，忽略过渡期毛刺 | 同步时序电路（工业标准方案）|

示例：$F = AB + \bar{A}C$ 在 $B=C=1$、$A$ 跳变时有冒险 → 加冗余项得 $F = AB + \bar{A}C + BC$。

> 注意这里的取舍：[[逻辑函数化简]]要把 $BC$ **删掉**（省门），消除冒险要把它**加回来**（保稳）。最简和最稳不是一回事。

### 各电路对比

| 电路 | 输入 | 输出 | 典型应用 |
|:---|:---|:---|:---|
| 半加器 | A,B | S, Cout | 最低位加法 |
| 全加器 | A,B,Cin | S, Cout | 多位加法基础单元 |
| 译码器 | $n$ 位 | $2^n$ 路 | 地址译码、数码管 |
| 编码器 | $2^n$ 路 | $n$ 位 | 键盘、中断控制 |
| MUX | $2^n$ 路 + $n$ 选择 | 1 路 | 数据路由、逻辑实现 |
| DEMUX | 1 数据 + $n$ 选择 | $2^n$ 路 | 数据分配 |
| 比较器 | 两个 $n$ 位数 | 3 种 | 大小判断、排序 |

### 基于 MSI 的组合逻辑设计

**用 MUX 实现任意函数**：$n$ 位地址的 MUX 输出是 $2^n$ 个最小项的选择求和，把真值表的值直接接到数据端即可。

**降维法**：用 $2^{n-1}$ 选 1 MUX 实现 $n$ 变量函数——把一个变量留作数据输入，其余 $n-1$ 个接地址端，每个数据端接入剩余变量的**残留函数**（0 / 1 / 原变量 / 反变量）。

| 芯片 | 规格 | 特点 |
|:---|:---|:---|
| 74HC151 | 8 选 1 | 有互补输出 $Y$、$\bar Y$ |
| 74HC153 | 双 4 选 1 | 两个独立 MUX，共享地址 |
| 74HC150 | 16 选 1 | 4 位地址 |

**用译码器实现任意函数**：低有效译码器的每个输出是 $\overline{m_i}$，把需要的几路接进一个 **NAND 门**，输出即为该函数（德摩根等效于把最小项或起来）。

**两种方法的成本对比**

| 方法 | 额外门数 | 适用场景 |
|:---|:---|:---|
| MUX 直连法 | 0 | 变量数 ≤ MUX 地址位数 |
| MUX 降维法 | 少量 | 变量数 = 地址位数 + 1 |
| 译码器 + NAND | 1 个 NAND | 任意 $n$ ≤ 译码器输入数 |

## 例题

### 例 1 · 用 8 选 1 MUX 实现 $F(A,B,C)=\Sigma m(1,3,5,6)$

$A,B,C$ 接地址端 $S_2,S_1,S_0$，数据端按真值表接 VCC/GND：

| 地址 ABC | 接法 | 说明 |
|:---|:---|:---|
| 000 | $D_0=0$ | $m_0 \notin \Sigma m$ |
| 001 | $D_1=1$ | $m_1 \in \Sigma m$ |
| 010 | $D_2=0$ | — |
| 011 | $D_3=1$ | $m_3 \in \Sigma m$ |
| 100 | $D_4=0$ | — |
| 101 | $D_5=1$ | $m_5 \in \Sigma m$ |
| 110 | $D_6=1$ | $m_6 \in \Sigma m$ |
| 111 | $D_7=0$ | — |

**零个额外门**——这就是 MSI 设计的价值。

### 例 2 · 用 3-8 译码器实现 $F(A,B,C)=\Sigma m(2,4,6,7)$

74HC138 输出低有效，即 $\bar Y_i = \overline{m_i}$：

$$F = m_2+m_4+m_6+m_7 = \overline{\overline{m_2}\cdot\overline{m_4}\cdot\overline{m_6}\cdot\overline{m_7}} = \overline{\bar Y_2 \cdot \bar Y_4 \cdot \bar Y_6 \cdot \bar Y_7}$$

把这四路接进一个 4 输入 NAND 门，输出即 $F$。**只用一个 NAND 门。**

### 例 3 · 四位可控加减法器

用 **74LS283**（4 位超前进位加法器）+ 4 个 XOR 门：

- $M=0$（加法）：$B_i \oplus 0 = B_i$ 直通，$C_0=0$ → $S = A + B$
- $M=1$（减法）：$B_i \oplus 1 = \bar B_i$ 取反，$C_0=1$ → $S = A + \bar B + 1 = A - B$

关键在于 $M$ 同时接到每个 XOR 的一端**和** $C_0$——「取反加一」正好是 $-B$ 的补码（见 [[原码反码补码]]）。**一个控制位就切换了加减法。**

### 例 4 · 8421 码 ↔ 余 3 码转换

- **8421 → 余 3**：$余3 = 8421 + 3$，用 74LS283，B 端接 $0011$，$C_0=0$
- **余 3 → 8421**：$8421 = 余3 - 3 = 余3 + 1101_2$（$-3$ 的 4 位补码），B 端接 $1101$，$C_0=0$

同一片加法器，换个常数就换了功能。

## 易错点

> [!warning] 半加器拿去做中间位
> 半加器**没有 $C_{in}$**，只能用在最低位。多位加法从第二位起必须用全加器。这是初学最常见的接线错误。

> [!warning] 编码器与译码器搞反
> **编码器**：多路输入 → 少位输出（$2^n \to n$），「压缩」。
> **译码器**：少位输入 → 多路输出（$n \to 2^n$），「展开」。
> 记方向：译码器把地址「翻译」成一根选中的线。

> [!warning] 忽略使能端和输出有效电平
> 74LS138 的输出是**低有效**（选中的那条是 0，其余是 1）。当成高有效直接接 OR 门，结果全反。同样，使能端不接对，整片芯片不工作。

> [!warning] MUX 降维时残留函数写错
> 降维法里每个数据端接的不是 0/1，而可能是**剩余变量或其反变量**。必须逐个地址组合代入原函数、把剩余变量解出来，不能凭感觉接。

> [!warning] 用最简式就万事大吉
> 最简与或式**最容易产生冒险**，因为它把相邻圈之间的「桥」（冗余项）全删了。要稳就得把冗余项加回来——见上文竞争与冒险一节。设计目标是最简还是最稳，要先想清楚。

> [!warning] 以为毛刺一定有害
> 后级如果是同步时序电路（时钟沿采样），过渡期的毛刺会被自然忽略，不用处理。只有当输出直接驱动异步逻辑、触发器的异步置位端或外部执行器时，毛刺才是真问题。**先看后级是什么，再决定要不要治。**
