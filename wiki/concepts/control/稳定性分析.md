> **一句话定义**：判断闭环极点是否全在左半平面。劳斯判据的价值在于——**不解方程就能知道有几个根在右半平面**。

> [!tip] 学习路径
> **前置**：[[传递函数]]（特征方程）、[[Laplace变换]]（极点↔时域行为）
> **本页**：稳定的充要条件、劳斯表、两种特殊情况、参数取值范围
> **后续**：→ [[稳态误差]]（稳定之后才谈精度）→ 根轨迹、Nyquist 判据

## 直觉

### 稳定性就是「极点在哪」

[[Laplace变换]] 已经建立了对应关系：极点 $p$ 对应时域模态 $e^{pt}$。

$$\mathrm{Re}(p)<0\ \Rightarrow\ e^{pt}\to0\quad\text{（衰减）}\qquad \mathrm{Re}(p)>0\ \Rightarrow\ e^{pt}\to\infty\quad\text{（发散）}$$

系统的零输入响应是各模态的叠加，**只要有一个模态发散，整体就发散**。于是：

> [!important] 线性系统稳定的充要条件
> **闭环特征方程的所有根，全部位于 $s$ 左半平面（实部严格小于零）。**
>
> 注意三点：
> - 是**闭环**极点，不是开环
> - 是**全部**，一个都不能例外
> - 虚轴上的根**不算稳定**——单根给出等幅振荡（临界稳定），重根给出 $t\sin\omega t$ 这样**发散**的响应

### 为什么需要劳斯判据

三阶以上的多项式没有通用求根公式，四阶五阶手算求根不现实。但我们**并不真的需要根的值**，只需要知道"有没有根在右边"。

劳斯判据正是回答这个问题的：**通过对系数做一系列有理运算，数出右半平面根的个数**。它不给你根在哪，但告诉你有几个跑到了右边——这恰好就是稳定性问题需要的全部信息。

$$\text{要的信息}：\text{右半平面根的个数}\qquad\text{付出的代价}：\text{几次除法}$$

## 原理与推导

### 必要条件：先做免费的筛查

特征方程 $a_ns^n+a_{n-1}s^{n-1}+\cdots+a_1s+a_0=0$ 稳定的**必要条件**是：

$$\textbf{所有系数同号，且无一为零}$$

**为什么**：若所有根都在左半平面，可写成 $\prod(s+\alpha_i)\prod(s^2+\beta_js+\gamma_j)$，其中 $\alpha_i,\beta_j,\gamma_j>0$。**全正系数相乘再相加，展开后不可能出现负号或零。**

> [!important] 这是必要条件，不是充分条件
> - 系数**有异号或缺项** ⟹ **一定不稳定**，可以直接下结论，不用列劳斯表
> - 系数**全部同号** ⟹ 还**不能**判定稳定，必须继续列表
>
> 例：$s^3+s^2+2s+8$ 系数全正，但劳斯表会显示它有两个右半平面根。**光看系数就说"全正所以稳定"是最常见的错误。**

### 劳斯表的构造

对 $a_ns^n+a_{n-1}s^{n-1}+\cdots+a_0=0$：

| | | | |
|:---|:---|:---|:---|
| $s^n$ | $a_n$ | $a_{n-2}$ | $a_{n-4}$ … |
| $s^{n-1}$ | $a_{n-1}$ | $a_{n-3}$ | $a_{n-5}$ … |
| $s^{n-2}$ | $b_1$ | $b_2$ | … |
| $s^{n-3}$ | $c_1$ | $c_2$ | … |
| ⋮ | ⋮ | | |
| $s^0$ | $a_0$ | | |

前两行由系数**隔行分组**填入，之后每一项由**上两行的第一列与对应列**做交叉相乘：

$$b_1=\frac{a_{n-1}a_{n-2}-a_na_{n-3}}{a_{n-1}},\qquad b_2=\frac{a_{n-1}a_{n-4}-a_na_{n-5}}{a_{n-1}}$$

$$c_1=\frac{b_1a_{n-3}-a_{n-1}b_2}{b_1},\qquad\cdots$$

**记忆法**：每个新元素 $=-\dfrac{1}{\text{左上角}}\times\begin{vmatrix}\text{上两行第一列}&\text{上两行本列右邻}\end{vmatrix}$，即"左上角分之负行列式"。

> [!important] 劳斯判据
> **首列元素变号的次数 = 右半平面根的个数。**
>
> 首列全部同号 ⟺ 无右半平面根 ⟺ **系统稳定**。

**整行同乘一个正数不影响结论**——为了简化计算，可以随时把某行约分。**但不能乘负数**，那会改变符号从而改变结论。

### 特殊情况一：首列出现 0，但该行不全为零

问题：下一行要除以这个 0，算不下去。

**解法（$\varepsilon$ 替代法）**：用一个无穷小正数 $\varepsilon$ 代替 0，继续列表，最后令 $\varepsilon\to0^+$ 考察首列符号。

> [!important] 这种情况意味着什么
> 出现这种情形时，系统**一定不稳定**（或临界稳定）——不可能是稳定的。$\varepsilon$ 法的作用只是帮你数清**究竟有几个根在右边**。

### 特殊情况二：整行全为零

问题：整行为零，后面无法继续。

**它的物理含义比计算方法更重要**：

> [!important] 整行全零 ⟹ 存在关于原点对称的根
> 全零行意味着特征方程含有一个**因子，其根关于原点对称**。三种可能：
> - 一对**共轭虚根** $\pm j\omega$ ⟹ **等幅振荡**（临界稳定）—— 最常见
> - 一对**实根** $\pm\sigma$ ⟹ 有一个在右半平面，不稳定
> - 两对**共轭复根** $\pm\sigma\pm j\omega$ ⟹ 不稳定
>
> **求参数临界值的题目，几乎都是让你找出全零行出现的条件**——那正是系统从稳定跨向不稳定的分界点，此时的 $\omega$ 就是等幅振荡频率。

**解法（辅助多项式法）**：

1. 用**全零行上面那一行**的系数构造辅助多项式 $A(s)$（次数按该行对应的 $s$ 幂次，且只含偶次或只含奇次项）
2. 对 $A(s)$ **求导**，用 $\dfrac{\mathrm dA}{\mathrm ds}$ 的系数替换全零行
3. 继续列表
4. **对称的那些根就是 $A(s)=0$ 的根**，可直接解出

## 例题

### 例 1 · 系数全正却不稳定（必要非充分的反例）

判断 $s^3+s^2+2s+8=0$ 的稳定性，并指出右半平面根的个数。

**先看必要条件**：系数 $1,1,2,8$ 全正无缺项 ✓ 通过筛查——**但这不代表稳定**。

**列劳斯表**：

| | 第一列 | 第二列 |
|:---|:---|:---|
| $s^3$ | $1$ | $2$ |
| $s^2$ | $1$ | $8$ |
| $s^1$ | $\dfrac{1\times2-1\times8}{1}=-6$ | $0$ |
| $s^0$ | $8$ | |

**首列**：$1,\ 1,\ -6,\ 8$

变号次数：$1\to-6$（**变号 1 次**），$-6\to8$（**变号 1 次**）

$$\boxed{2\ \text{个右半平面根，系统不稳定}}$$

**验证**：$s^3+s^2+2s+8=(s+2)(s^2-s+4)$。后者的根为 $\dfrac{1\pm j\sqrt{15}}{2}$，实部 $+0.5>0$ ✓ 确有两个右半平面根。

> [!tip] 这题在考什么
> **系数全正只是及格线**。这个反例值得记住——它专门用来打消"系数全正就稳定"的错觉。

### 例 2 · 求参数稳定范围与临界振荡频率

单位反馈系统开环 $G_k(s)=\dfrac{K}{s(s+1)(s+2)}$。求使闭环稳定的 $K$ 范围，并求临界稳定时的振荡频率。

**闭环特征方程**：$s(s+1)(s+2)+K=0$，即

$$s^3+3s^2+2s+K=0$$

**必要条件**：$K>0$。

**劳斯表**：

| | 第一列 | 第二列 |
|:---|:---|:---|
| $s^3$ | $1$ | $2$ |
| $s^2$ | $3$ | $K$ |
| $s^1$ | $\dfrac{3\times2-1\times K}{3}=\dfrac{6-K}{3}$ | $0$ |
| $s^0$ | $K$ | |

**首列全正的条件**：

$$\frac{6-K}{3}>0\ \Rightarrow\ K<6\qquad\text{且}\qquad K>0$$

$$\boxed{0<K<6}$$

**临界情况 $K=6$**：$s^1$ 行变为全零。用上一行（$s^2$ 行）构造辅助多项式：

$$A(s)=3s^2+K=3s^2+6=0\quad\Rightarrow\quad s^2=-2\quad\Rightarrow\quad s=\pm j\sqrt2$$

$$\boxed{\omega=\sqrt2\approx1.414\,\mathrm{rad/s}}$$

**含义**：$K=6$ 时系统处于**等幅振荡**的临界状态，振荡频率 $\sqrt2\,\mathrm{rad/s}$。$K>6$ 后这对根越过虚轴进入右半平面，系统发散。

> [!tip] 这题在考什么
> 这是劳斯判据**最典型的用法**：不是判断一个具体系统稳不稳，而是**反求参数的允许范围**。全零行给出的临界点同时提供了两个信息——临界增益和振荡频率。

### 例 3 · 首列出现 0（$\varepsilon$ 替代法）

判断 $s^4+2s^3+s^2+2s+3=0$ 的稳定性。

**劳斯表**：

| | 第一列 | 第二列 | 第三列 |
|:---|:---|:---|:---|
| $s^4$ | $1$ | $1$ | $3$ |
| $s^3$ | $2$ | $2$ | $0$ |
| $s^2$ | $\dfrac{2\times1-1\times2}{2}=\mathbf{0}$ | $\dfrac{2\times3-1\times0}{2}=3$ | |

首列出现 $0$，但该行**不全为零**（第二列是 3）——用 $\varepsilon$ 替代：

| | 第一列 | 第二列 |
|:---|:---|:---|
| $s^2$ | $\varepsilon$ | $3$ |
| $s^1$ | $\dfrac{2\varepsilon-2\times3}{\varepsilon}=\dfrac{2\varepsilon-6}{\varepsilon}$ | $0$ |
| $s^0$ | $3$ | |

$\varepsilon\to0^+$ 时：

$$\frac{2\varepsilon-6}{\varepsilon}\approx\frac{-6}{\varepsilon}\to-\infty\quad(\textbf{负})$$

**首列**：$1,\ 2,\ \varepsilon(+),\ -\infty,\ 3$

变号：$\varepsilon(+)\to-\infty$（**1 次**），$-\infty\to3$（**1 次**）

$$\boxed{2\ \text{个右半平面根，系统不稳定}}$$

> [!tip] $\varepsilon$ 法的操作要点
> - $\varepsilon$ 取**正**的无穷小（取负也能得到同样的右半平面根数，但中间符号会全反，容易搞混，统一取正）
> - 只在**最后**才让 $\varepsilon\to0$，中间保留符号表达式
> - 出现这种情况时系统**必然不是稳定的**，$\varepsilon$ 法只是帮你数清右半平面根的个数

## 易错点

> [!warning] 把必要条件当充要条件
> 「系数全正 ⟹ 稳定」**是错的**（例 1）。正确的用法是：
> - 系数有异号或缺项 → 直接判定**不稳定**，省下列表的功夫
> - 系数全正 → **必须**继续列劳斯表
>
> 只有**二阶系统** $as^2+bs+c$ 才有"系数全正即稳定"这个特权，三阶以上不成立。

> [!warning] 对开环特征方程用劳斯判据
> 判定稳定性用的是**闭环**特征方程 $1+G_k(s)H(s)=0$，即把开环传函的分子分母相加。
>
> 常见错误是直接拿开环分母去列表。开环稳定与闭环稳定是**两回事**——开环不稳定的系统可以靠反馈稳住，反之开环稳定的加了反馈也可能失稳。

> [!warning] 整行全零时用错行构造辅助多项式
> 辅助多项式取的是**全零行的上一行**，不是全零行本身（它已经全是 0 了），也不是再上一行。
>
> 而且构造后要**求导**再填回去，不是直接把辅助多项式的系数填进全零行。

> [!warning] 把虚轴上的根算作稳定
> 虚轴根不满足"实部严格小于零"。单对共轭虚根给出等幅振荡，叫**临界稳定**，工程上按不可用处理；虚轴**重根**则会给出 $t\sin\omega t$ 这样**发散**的响应，是彻底的不稳定。

> [!warning] 劳斯表整行乘以负数
> 为简化计算可以给某行同乘**正数**，符号序列不变，结论不受影响。乘负数会翻转该行符号，**变号次数就错了**。

> [!warning] 对含 $e^{-\tau s}$ 的系统硬套劳斯判据
> 劳斯判据要求特征方程是**多项式**。纯延迟环节不是有理函数，没有有限阶多项式形式。
>
> 含延迟必须走频域法（Nyquist、Bode），或先用 Padé 把 $e^{-\tau s}$ 近似成有理式再用代数判据。见 [[传递函数]]。
