## 直觉

一个真实系统有控制器、执行器、被控对象、传感器好几块，每块都有自己的 $G(s)$。**方框图就是这些传函的接线图**：把结构画出来，再用几条代数规则把整张图压成一个 $\Phi(s)$。

三种连接对应三种代数运算，一一对应，非常干净：

| 图上怎么接 | 代数上怎么算 |
|:---|:---|
| 串联（首尾相接） | 相乘 |
| 并联（共享输入、输出相加） | 相加 |
| 反馈（输出绕回输入） | $\dfrac{G}{1+GH}$ |

第三条是全部控制理论的核心。它说明一件事：**只要 $GH$ 足够大，$\Phi\approx\frac{G}{GH}=\frac{1}{H}$——闭环特性几乎只由反馈通道决定，被控对象自身的不确定性被压掉了。** 这就是反馈能对抗参数漂移和扰动的根本原因，也是为什么工程上宁可牺牲增益也要加反馈。

化简的思路永远是**从最内层回路往外剥**，一层剥成一个框，直到只剩一个。

## 原理与推导

### 基本图形元素

| 元素         | 符号             | 含义                     |
| :--------- | :------------- | :--------------------- |
| **方框（环节）** | $\boxed{G(s)}$ | 一个子系统，输出 = $G(s)$ × 输入 |
| **信号线**    | →              | 携带信号（Laplace 变换后的变量）   |
| **比较点**    | ⊕              | 信号相加/相减，可有多路输入         |
| **分支点**    | •              | 同一信号引出到多处，值不变          |

> [!important] 方框内只写传递函数 $G(s)$，不写时域表达式。

### 三种基本连接

**串联（级联）**

$$G_{等效}(s) = G_1(s)\cdot G_2(s)\cdots G_n(s)$$

**并联**（共享输入，输出相加）

$$G_{等效}(s) = G_1(s) \pm G_2(s) \pm \cdots \pm G_n(s)$$

**反馈**（最重要）

```
R(s) →⊕→ E(s) → G(s) → C(s)
        ↑                  |
        └──── H(s) ←───────┘
              (负反馈)
```

| 变量     | 含义                |
| :----- | :---------------- |
| $R(s)$ | 参考输入（给定值）         |
| $E(s)$ | 误差信号 $= R - B$    |
| $G(s)$ | 前向通道传递函数          |
| $H(s)$ | 反馈通道传递函数          |
| $B(s)$ | 反馈信号 $= H(s)C(s)$ |
| $C(s)$ | 输出                |

$$\boxed{\Phi(s) = \frac{C(s)}{R(s)} = \frac{G(s)}{1 + G(s)H(s)}}$$

> [!important] 推导（三行）
> $C = GE = G(R - HC)$
> $C(1+GH) = GR$
> $\Phi = \dfrac{G}{1+GH}$；单位负反馈（$H=1$）时 $\Phi=\dfrac{G}{1+G}$

**开环传递函数**：$G_{\text{open}}(s) = G(s)H(s)$（断开反馈后，前向 × 反馈）

### 等效变换规则

化简时逐步应用以下规则消除交叉。

**相加点的移动**

| 操作 | 规则 |
|:-----|:-----|
| 相加点越过方框**前移**（向输入侧）| 在移动支路上串入 $\dfrac{1}{G(s)}$ |
| 相加点越过方框**后移**（向输出侧）| 在移动支路上串入 $G(s)$ |

### 化简步骤

1. 标出所有信号变量（$R,E,C$ 及中间节点）
2. 先化简**最内层回路**为单框
3. 再化简外层，重复直到只剩一个框
4. 有交叉支路时，先移动相加点/分支点消除交叉

### 误差传递函数

$$\Phi_e(s) = \frac{E(s)}{R(s)} = \frac{1}{1 + G(s)H(s)}$$

注意 $\Phi(s)\cdot H(s) + \Phi_e(s) = 1$；当 $H=1$ 时化为 $\Phi + \Phi_e = 1$。

## 例题

### 例 1 · 单位负反馈系统

$$G(s) = \frac{10}{s(s+1)}, \quad H(s) = 1$$

$$\Phi(s) = \frac{G}{1+G} = \frac{\dfrac{10}{s(s+1)}}{1+\dfrac{10}{s(s+1)}} = \frac{10}{s^2+s+10}$$

对照标准二阶形式：$\omega_n=\sqrt{10}\approx3.16$，$2\zeta\omega_n=1 \Rightarrow \zeta\approx0.158$——阻尼很小，会有明显超调。

### 例 2 · 含内环的双回路系统

```
R →⊕→ G₁ →⊕→ G₂ → C
    ↑        ↑        |
    │        └─ H₂ ←─┤
    └────── H₁ ←──────┘
```

**步骤 1** 化简内环：

$$G_{内}(s) = \frac{G_2}{1 + G_2 H_2}$$

**步骤 2** 化简外环（$G_1$ 与 $G_{内}$ 串联作前向通道）：

$$\Phi(s) = \frac{G_1 G_{内}}{1 + G_1 G_{内} H_1} = \frac{G_1 G_2}{(1+G_2 H_2) + G_1 G_2 H_1}$$

> 分母的两项分别来自内环和外环——**每多一个回路，分母就多一项**，这是检查化简对不对的快速办法。

## 易错点

> [!warning] 相加点与分支点的补偿方向相反
> 这是本章最容易错的一条：
> - **相加点前移** → 支路串 $1/G$；**相加点后移** → 支路串 $G$
> - **分支点前移** → 支路串 $G$；**分支点后移** → 支路串 $1/G$
>
> 两者的补偿**互为倒数**。判断方法不是背，而是验算：移动前后，那条支路上的信号值必须保持不变。

> [!warning] 负反馈公式的分母符号
> 负反馈是 $\dfrac{G}{1+GH}$，正反馈是 $\dfrac{G}{1-GH}$。比较点上标的是「−」，公式里却是「+」——因为负号已经在推导 $C=G(R-HC)$ 时用掉了。看到图上是负反馈就写 $1+GH$，别再减一次。

> [!warning] 开环传函漏掉 $H$
> 开环传函是 $G(s)H(s)$，不是 $G(s)$。只有单位反馈时两者才相同。求稳定裕量、画 Bode/Nyquist 用的都是 $GH$，这里漏了 $H$ 后面全错。

> [!warning] 分支点移动时把值改了
> 分支点引出的信号**值不变**——分支不消耗、不改变信号。移动分支点是为了让拓扑好看，补偿的目的正是维持这个不变量。

> [!warning] 交叉回路直接套公式
> 回路之间有交叉（不是干净的嵌套）时，不能直接用 $\frac{G}{1+GH}$ 逐层套。必须先移动相加点/分支点把交叉解开，或者改用 Mason 公式（[[信号流图]]）。
