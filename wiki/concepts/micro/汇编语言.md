> **一句话定义**：汇编语言用助记符和符号地址直接描述 8086 指令，是连接机器指令、寄存器、内存和程序控制流程的低级程序设计语言。

## 直觉

高级语言隐藏了寄存器和地址，汇编语言把它们全部显式写出：数据在哪个寄存器、内存操作数如何计算、哪条指令改变哪些标志，都由程序员负责。它难写，却能让每一个时钟周期和每一个字节的去向都可追踪。

学习 8086 汇编最有效的方式是同时问三件事：指令对什么数据操作，数据通过什么寻址方式取得，执行后哪些标志或寄存器改变。`MOV AX,[BX+SI]` 不只是“移动数据”，还隐含了默认段寄存器和有效地址计算规则。

## 原理与推导

### 指令的一般结构

一条指令通常包含操作码和操作数字段。汇编器把助记符、寄存器名、标号和常量翻译成机器码；伪指令不生成 CPU 执行的操作码，而是指导汇编器分配空间、定义符号或组织段。

### 8086 指令系统分类

| 类别 | 代表指令 | 主要作用 | 典型注意事项 |
|:---|:---|:---|:---|
| 数据传送 | `MOV`、`PUSH`、`POP`、`XCHG` | 寄存器、内存、栈之间传数据 | `MOV` 不能内存到内存 |
| 算术运算 | `ADD`、`ADC`、`SUB`、`SBB`、`INC`、`DEC` | 加减与多字节运算 | `INC/DEC` 不影响 `CF` |
| 逻辑运算 | `AND`、`OR`、`XOR`、`NOT`、`TEST` | 屏蔽、置位、清零、测试 | `TEST` 只改标志不保存结果 |
| 移位旋转 | `SHL/SAL`、`SHR`、`SAR`、`ROL`、`ROR` | 位移与乘除 2 的幂 | `SAR` 保留符号位 |
| 串操作 | `MOVS`、`LODS`、`STOS`、`CMPS`、`SCAS` | 字符串搬移、比较、查找 | 受 `DF` 与 `REP` 影响 |
| 控制转移 | `JMP`、条件转移、`CALL`、`RET` | 分支、调用与返回 | 条件转移看标志位 |
| 处理器控制 | `NOP`、`HLT`、`CLI`、`STI`、`CLD`、`STD` | 控制 CPU 或标志 | `CLI/STI` 影响中断允许 |

> [!important] 操作数宽度必须匹配
> `MOV AL,1234H` 错误，因为 `AL` 只有 8 位；应改成 `MOV AX,1234H` 或把常量写成 8 位范围内的值。内存操作数常需用 `BYTE PTR` / `WORD PTR` 消除宽度歧义。

### 常用寻址方式

| 寻址方式 | 例子 | 有效地址 / 操作数 |
|:---|:---|:---|
| 立即寻址 | `MOV AX,1234H` | 操作数直接在指令中 |
| 寄存器寻址 | `MOV AX,BX` | 操作数在寄存器 |
| 直接寻址 | `MOV AX,[1234H]` | $EA=1234H$ |
| 寄存器间接 | `MOV AX,[BX]` | $EA=BX$，默认 `DS` |
| 基址寻址 | `MOV AX,[BX+10H]` | $EA=BX+10H$ |
| 变址寻址 | `MOV AX,[SI+10H]` | $EA=SI+10H$ |
| 基址变址 | `MOV AX,[BX+SI]` | $EA=BX+SI$ |
| 相对寻址 | `JNZ NEXT` | $IP$ 加位移量 |

8086 有效地址组合只能使用规定的 `BX/BP` 与 `SI/DI` 组合，不能任意写三个寄存器。含 `BP` 时默认段为 `SS`，含 `BX`、`SI`、`DI` 时默认段为 `DS`；段超越前缀可以临时改变默认段。

### 常见指令语义

`CMP dst,src` 本质上执行 `dst-src` 但不保存结果，只更新标志；随后 `JE/JZ`、`JA/JB` 等条件转移读取这些标志。`TEST dst,src` 本质上执行按位与但不保存结果，常用于判断某些位是否为 0。

| 比较对象 | 大于 | 小于 | 等于 |
|:---|:---|:---|:---|
| 无符号数 | `JA`（`CF=0且ZF=0`） | `JB`（`CF=1`） | `JE/JZ` |
| 有符号数 | `JG`（`ZF=0且SF=OF`） | `JL`（`SF≠OF`） | `JE/JZ` |

### 伪指令

| 伪指令 | 功能 | 例子 |
|:---|:---|:---|
| `DB` | 定义字节 | `BUF DB 10 DUP(?)` |
| `DW` | 定义字 | `NUM DW 1234H` |
| `EQU` | 定义常量，不分配存储 | `CR EQU 0DH` |
| `DUP` | 重复初始化或预留 | `TAB DB 20 DUP(0)` |
| `SEGMENT/ENDS` | 定义段起止 | `DATA SEGMENT ... DATA ENDS` |
| `ASSUME` | 告知汇编器段寄存器对应的段 | `ASSUME DS:DATA` |
| `PROC/ENDP` | 定义过程 | `MAIN PROC ... MAIN ENDP` |
| `END` | 指定源程序结束及入口 | `END MAIN` |

### 常见程序结构

```asm
DATA SEGMENT
    NUM DW 1234H
DATA ENDS

CODE SEGMENT
    ASSUME CS:CODE, DS:DATA
MAIN PROC FAR
    MOV AX, DATA
    MOV DS, AX
    MOV AX, NUM
    ; 主程序逻辑
    MOV AX, 4C00H
    INT 21H
MAIN ENDP
CODE ENDS
END MAIN
```

初始化 `DS` 时不能直接写 `MOV DS,DATA`，通常必须先把段地址送入通用寄存器，再传给段寄存器。过程调用前要明确近调用/远调用和栈平衡规则。

### 循环、分支与栈

`LOOP label` 自动执行 `CX←CX-1`，当 `CX≠0` 时转移；如果循环体还修改 `CX`，就会破坏计数。栈按字操作，`PUSH` 先减 `SP` 再写入，`POP` 先读出再加 `SP`。

## 例题

### 例 1 · 数组求和

有 5 个无符号字节从 `BUF` 开始存放，求和结果放入 `AX`。

先令 `SI` 指向数组、`CX=5`、`AX=0`。每次用 `[SI]` 取一个字节时，必须先扩展到 16 位，避免直接把 8 位操作数加到 16 位寄存器：

```asm
XOR AX, AX
MOV SI, OFFSET BUF
MOV CX, 5
NEXT: XOR BX, BX
      MOV BL, [SI]
      ADD AX, BX
      INC SI
      LOOP NEXT
```

循环 5 次后，`AX` 等于 $\sum_{i=0}^{4}BUF[i]$，`BX` 每轮保存当前字节的零扩展值。

$$\boxed{AX=BUF[0]+BUF[1]+BUF[2]+BUF[3]+BUF[4]}$$

### 例 2 · 判断无符号数大小

比较 `AX` 与 `BX`，若 `AX` 大于 `BX`，则把 `CX` 置为 1，否则置为 0。

```asm
XOR CX, CX
CMP AX, BX
JBE NOT_GREATER
MOV CX, 1
NOT_GREATER:
```

`CMP` 计算 `AX-BX`；无符号“大于”要求 `CF=0 且 ZF=0`，因此可以用 `JA`，也可以跳过“大于等于”分支使用 `JBE`。这里 `JBE` 覆盖 `AX<BX` 或 `AX=BX`。

$$\boxed{AX>BX\Rightarrow CX=1；AX\le BX\Rightarrow CX=0}$$

### 例 3 · 物理地址对应的寻址

已知 `DS=2000H`、`BX=0100H`、`SI=0020H`，执行 `MOV AX,[BX+SI+10H]`，求访问的物理地址。

有效地址为

$$EA=0100H+0020H+0010H=0130H$$

该地址含 `BX/SI` 且未使用 `BP`，默认段为 `DS`，所以

$$PA=2000H\times10H+0130H=20130H$$

$$\boxed{EA=0130H,\quad PA=20130H}$$

## 易错点

> [!warning] 立即数和内存操作数不是一回事
> `MOV AX,NUM` 取的是变量内容，`MOV AX,OFFSET NUM` 取的是变量偏移地址。题目问“地址”时不能漏写 `OFFSET`。

> [!warning] `CMP` 不会保存减法结果
> `CMP AX,BX` 只更新标志，不会改变 `AX`。如果后面要使用差值，必须显式写 `SUB` 或另存结果。

> [!warning] 有符号条件转移不能用于无符号比较
> `JA/JB` 看 `CF、ZF`，`JG/JL` 看 `SF、OF、ZF`。两套条件混用，数据刚好跨过 `7FFFH/8000H` 时最容易出错。

> [!warning] 段寄存器不能用立即数直接装载
> `MOV DS,1234H` 不是合法的 8086 指令；要先 `MOV AX,1234H`，再 `MOV DS,AX`。

> [!warning] `LOOP` 隐含修改 `CX`
> 循环体若又使用 `CX` 作乘法高字或临时数据，会导致循环次数改变。需要嵌套循环时应分别保存外层计数。
