## 直觉

### 这门课在补哪一块拼图

你已经知道两头：

- **上面**：[[基础语法]] 那样的高级语言，写 `a = b + c` 就行
- **下面**：[[组合逻辑电路]] 那样的门电路，与或非搭出加法器

中间断了一大截——**`a = b + c` 怎么变成加法器输入端的电平？** 微机原理补的就是这一截：

$$\text{高级语言}\longrightarrow\underbrace{\text{指令}\longrightarrow\text{寄存器/ALU 动作}\longrightarrow\text{总线时序}}_{\textbf{本课}}\longrightarrow\text{门电路}$$

**所以这门课的知识点看着杂（寄存器、指令、时序、芯片一大堆），主线其实只有一条：跟着一次数据传输，从指令一路走到引脚。**

### 四个「翻译」层

课程的全部内容可以摆进四次翻译：

| 层 | 从什么 → 到什么 | 关键机制 |
|:---|:---|:---|
| 一 | 源程序 → 机器码 | 汇编、伪指令、段定义 |
| 二 | 逻辑地址 → 物理地址 | **段基址 $\times16$ + 偏移** |
| 三 | 指令 → 总线动作 | 取指、译码、执行、$T_1\!\sim\!T_4$ 时序 |
| 四 | 地址 → 具体芯片的片选 | **地址译码**（全译码 / 部分译码 / 线选）|

第二层和第四层是本课两个最大的失分点，都是「地址」的问题，但方向相反：**第二层是 CPU 内部把两个 16 位拼成 20 位；第四层是 CPU 外部把 20 位拆开，一部分选芯片、一部分选片内单元。**

## 核心脉络

### 一、从硬件结构到执行过程

[[8086微处理器]]：EU 与 BIU 并行、6 字节预取队列、寄存器组的隐含用途、FLAGS 的 `CF`/`OF` 分工。

**核心洞察**：取指与执行重叠是流水线的雏形；转移指令要清空队列，这解释了「为什么分支昂贵」——一个从 8086 延续到现代 CPU 分支预测的问题。

### 二、从逻辑地址到物理地址

$$\text{物理地址}=\text{段寄存器}\times16+\text{偏移量}$$

段重叠导致**同一物理地址有多种「段:偏移」写法**，指针比较必须在物理地址层面做。

### 三、从指令到总线时序

[[汇编语言]]：七种寻址方式、段默认规则（**`BP`→`SS`**）、指令分类。

总线读周期 $T_1\!\sim\!T_4$：$T_1$ 送地址并由 `ALE` 锁存（因为地址数据线复用），$T_2$ 转数据，$T_3$ 采样，$T_4$ 结束；存储器慢就插 $T_W$。

### 四、从地址到片选：接口的共同套路

所有接口芯片（8255、8253、8259、8251）的学习方法完全一样，套一个模板即可：

| 问题 | 要查什么 |
|:---|:---|
| 芯片占几个端口地址？ | 片内寄存器数量 → 决定用几根低位地址线 |
| 片选 `CS` 怎么接？ | 剩余高位地址线经译码器 → 决定端口基地址 |
| 怎么初始化？ | **控制字**格式（每一位什么含义）|
| 怎么用？ | 读/写哪个端口、什么时机 |

**不要把四片芯片当四套知识背**——用上面这个「端口地址 → 片选 → 控制字 → 读写」的框架去套，四片能省下大半功夫。但框架只管组织记忆，**各自的控制字格式、时序要求和专用功能仍须分别掌握**，不能把一片的规则直接搬到另一片上。

## 公式 / 概念速查

| 项目 | 内容 |
|:---|:---|
| 物理地址 | $\text{段}\times16+\text{偏移}$（十六进制即段末尾添 0 后相加）|
| 寻址空间 | 20 根地址线 → $2^{20}=1\,\mathrm{MB}$ |
| 段最大长度 | 偏移 16 位 → $64\,\mathrm{KB}$ |
| 段间最小间隔 | 16 字节（1 节 paragraph）|
| 无符号溢出判据 | `CF` = 1 |
| 有符号溢出判据 | `OF` = $C_{in}\oplus C_{out}$ = 1 |
| 合法基址变址组合 | `[BX+SI]` `[BX+DI]` `[BP+SI]` `[BP+DI]` **仅此四种** |
| 默认段 | `BX/SI/DI`→`DS`；**`BP`→`SS`**；`DI`(串目的)→`ES`；`IP`→`CS` |
| 总线周期 | $4T$（+ $n$ 个 $T_W$）|
| 存储器位扩展 | 加宽数据位：$8\!\times\!8\mathrm K \to 16\!\times\!8\mathrm K$ 需 2 片，**地址线并联、数据线分开** |
| 存储器字扩展 | 加深容量：$8\!\times\!8\mathrm K \to 8\!\times\!16\mathrm K$ 需 2 片，**数据线并联、用高位地址片选** |

## 题型抓手

| 见到题目问 | 先做这一步 |
|:---|:---|
| 求物理地址 | 段寄存器**十六进制末尾添 0**，再加偏移。别转十进制 |
| 判断两指针是否同一单元 | 各自算出**物理地址**再比，不能比段或偏移 |
| 求某指令的 EA | 先认出寻址方式，再套 $\text{基址}+\text{变址}+\text{位移}$ |
| 出现 `BP` | 立刻想 `SS`，除非有段超越前缀 |
| 判断溢出 | 先问「题目当它是有符号还是无符号」，再选 `CF` 或 `OF` |
| 存储器扩展要几片 | 先看**位**够不够（位扩展），再看**容量**够不够（字扩展）|
| 求端口地址范围 | 写出译码器输入的地址位，未参与译码的位取全 0 和全 1 得上下界 |
| 接口芯片初始化 | 按**控制字格式**逐位填，再确定写入哪个端口 |
| 算总线周期时间 | $T=1/f$，标准 $4T$，存储器慢则加 $T_W$ |

## 易错点（全局层面）

> [!warning] 把这门课当成「背芯片手册」
> 四片可编程接口芯片看着要背很多，其实共用同一个套路：**占几个端口 → 片选怎么接 → 控制字怎么填 → 怎么读写**。抓住模板，四片一起就通了；一片一片死记，考场上必然串。

> [!warning] 段基址「末尾添 0」在十进制下做
> 添 0 是**十六进制**的说法（$\times16$）。中途转成十进制再添 0 就变成了 $\times10$，全盘皆错。**全程十六进制**。

> [!warning] 算到 EA 就交卷
> 题目问「物理地址」时，EA 只是第一步，还要 $\text{段}\times16+\mathrm{EA}$。这是最可惜的一类失分——方法全对，少走一步。

> [!warning] 忽略「这道题把数据当有符号还是无符号」
> `CF` 和 `OF` 是 CPU 同时算出来的两个结果，选哪个取决于你的解释。题干里「带符号数」「无符号数」几个字决定了答案，读题时要圈出来。

> [!warning] 位扩展与字扩展搞反
> - **位扩展**（数据位不够）：地址线**并联**，数据线**各接各的**，片选**并联**
> - **字扩展**（容量不够）：数据线**并联**，用**高位地址**经译码器产生不同片选
>
> 记法：**缺什么就分开接什么**——缺位分数据线，缺容量分片选。
